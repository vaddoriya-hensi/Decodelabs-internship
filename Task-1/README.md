# 🍽️ La Tavola Restaurant Website

La Tavola is a modern and responsive restaurant website built using HTML5 and CSS3. The project is designed to provide an elegant online presence for an Italian restaurant, featuring a visually appealing homepage, detailed menu section, restaurant story, image gallery, customer testimonials, and an online table reservation form. The website focuses on clean design, smooth navigation, and an engaging user experience.

## ✨ Features

- Responsive navigation bar
- Attractive hero section with call-to-action buttons
- About Us section showcasing restaurant history
- Chef's Special Menu with food cards and pricing
- Customer Reviews & Testimonials section
- Online Table Reservation Form
- Restaurant Image Gallery
- Footer with contact details, opening hours, and newsletter subscription
- Modern dark theme with red accent colors

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome Icons

## 🎯 Project Objective

The goal of this project is to create a professional restaurant website that demonstrates front-end web development skills using only HTML and CSS. It highlights responsive layouts, typography, color schemes, card-based design, and user-friendly navigation.
